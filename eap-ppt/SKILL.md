# eap-ppt

本技能在仓库中的目录名为 **`eap-ppt/`**。使用 [skills.sh](https://skills.sh/) 类 CLI 仅安装本技能时：`npx skills add <本仓库> --skill eap-ppt`（`--skill` 与目录名一致）。

## 适用范围

| 使用本技能 | 不使用本技能 |
| ---------- | ------------ |
| 按本文规范 **从零编写** 新的 `.pptx`（推荐 PptxGenJS） | 用 `markitdown`、解包 XML 等 **读取** 已有 `.pptx` |
| 视觉与结构对齐下文「品牌与版式」 | 以用户上传的任意 `.pptx` 为母版做 **编辑/套版** |

画布与 **PptxGenJS**：`pres.layout = 'LAYOUT_WIDE'`（13.3" × 7.5"），与下述 EMU 画布等价（1 in = 914400 EMU）。

| 画布（EMU） | 约（英寸） |
| ----------- | ---------- |
| 12192000 × 6858000 | 13.33 × 7.5 |

## 文本样式

| 元素 | 字号 | 字重 | 颜色 | 行距 | 对齐 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 页面标题 | 20pt | 粗体 | `333333` | 约 90% 或 1.5 倍行距 | 左 |
| 正文 L1 / L2 / L3 / L4+ | 28 / 24 / 20 / 18pt | 常规 | `333333` | 同上 | 左 |
| 幻灯片编号 | 10.5pt | 常规 | `D8D8D8` | — | 居中 |
| 页眉英文标签 | 9pt | 常规 | 约 75% 亮度灰 | — | 左，**全大写**（如 `ABOUT US`） |

封面级大标题可用约 36–44pt；段前 0、段后约 8–10pt。

## 版式类型

1. **封面**：全屏背景图、居中大标题、右下页码。  
2. **白色内容页**：底 `FBFBFB`；左上 Logo；左侧中文标题 + 英文标签；右上企业标识；右下页码；正文区左对齐。  
3. **图片网格**：白底；内容区 **3 列等宽图**；标题区在左。  
4. **空白背景**：整页背景图 + 页码，大块自定义内容。

## 固定元素（英寸，便于 PptxGenJS）

由 EMU÷914400 换算，可按需四舍五入到小数点后两位。

| 元素 | x | y | 宽×高（若适用） |
| ---- | --- | --- | ---------------- |
| Logo | 0.54 | 0.46 | 0.53 × 0.29 |
| 中文页面标题 | 1.03 | 0.42 | — |
| 英文页眉标签 | 2.20 | 0.40 | — |
| 企业标识（右上） | 11.28 | 0.50 | — |
| 幻灯片编号 | 12.83 | 7.10 | — |

**图片网格（量级）：** 单列宽约 **3.72 in**，列间距约 **0.22 in**（对应约 3400000 / 200000 EMU）。

**边距：** 内容区距幻灯片边缘至少 **0.5 in**；勿压住 Logo、企业标识、页码与标题区。

## 避免

- 不要用与本规范无关的配色当主色。  
- 不要将正文大面积居中（页码除外）。  
- 不要在标题下加「AI 味」装饰线；用留白或色块区分。  
- 低对比：浅底勿用浅灰正文；深底正文用白。  
- 列表用 PptxGenJS 的 `bullet: true`，勿手写 `•`。  
- 文本框与形状对齐时注意 `margin: 0`（见 pptxgenjs.md）。

## 交付前自检

1. 在 PowerPoint / WPS 中打开，检查溢出、重叠、字体回退。  
2. 对照本文核对主色与固定元素大致位置。  
3. 搜索是否残留明显占位文案（如 lorem、xxxx）。

本技能 **不包含** 仓库内 Python 解包、PDF 导出或缩略图脚本；若需要自动化质检，请在项目外自行配置工具链。
